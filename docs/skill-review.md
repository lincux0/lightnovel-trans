# 技能适用性与发布前检查

## 结论与边界

该技能可作为常见文字型日文轻小说中文翻译的工作流，覆盖有/无对照译本、首次建库、续卷、番外时间线、译稿审核、授权修订和按需 EPUB 交付。它不依赖某个系列的角色、译法或出版社文件名。

“适用于多数”是对流程的适配判断，不是多作品测试统计。本次没有翻译多个新系列、构建多种出版社 EPUB 或验证全部阅读器；不承诺翻译准确率、OCR 质量、受限输入处理或全格式自动转换。

| 输入/目标 | 适用性 | 额外条件 |
|---|---|---|
| 可重排 EPUB、文字为主 | 适合 | 可靠源块映射、内联语义保留、实际包/CSS 适配。 |
| TXT | 附带基础适配器 | 编码和标题/硬换行规则经抽样确认；使用新输出目录。 |
| 无官方中译、第一次翻译 | 适合 | 从原文逐步建术语与风格，TM 可为空。 |
| 已有系列中译、跨卷/早期番外 | 适合 | 复核例句质量及人物关系、时间线，不盲目全局替换。 |
| 仅译稿或只读审核 | 适合 | 跳过 EPUB；只读模式不写入。 |
| DOCX/HTML | 条件适用 | 另备适配器，核对脚注、图文、表格/文本框与 ruby。 |
| PDF/OCR、固定版式、复杂图文 | 需专项评估 | 先确认可靠文本、阅读顺序和语义信息，没有完整自动化实现。 |

## 原稿问题与本次修订

1. **脚本假通过**：假名范围漏检片假名；结构检查跳过缺失译章、忽略额外译章与空输入。改为完整范围扫描和输入/章节集合失败检查。
2. **TXT 数据完整性**：重跑留下旧章节，短章筛选可能删除源文，硬换行合并破坏分隔符和缩进。改为拒绝非空输出、短章仅提示、保持独立结构条目。
3. **本地依赖与过拟合**：删去硬编码的 Windows 项目路径，把作品特定译法、段数、样式与阈值改成项目配置或示例。明确只附三个脚本。
4. **语义与结构混淆**：增加否定范围、授受方向、视角和时间线核对；机械报警仅作线索。保留默认 1:1 以便回写，经允许重分段则另维护映射。
5. **特殊内容损失**：明确 ruby/外字/脚注可携带语义，不能一律清空内联元素；需完整提取与人工判断。
6. **任务与交付范围**：分清只读审核与授权修订；允许仅译稿/报告，不自动制作 EPUB 或发布。
7. **EPUB 通用性**：从 container/OPF 探测真实路径与模板；补充 EPUB 3 元数据、导航和标识要求；区别浏览器预览、机械结构检查与阅读器实测。
