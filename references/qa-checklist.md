# 自检与 QA 清单

> 分三级：每章结构 → 全卷 QA → 打包验证。全部脚本化，结果以实际运行输出为准。

## 一级：每章结构 1:1（翻译中/完成后立即）

- [ ] 非空行数一致（含标题行、◆◆◆、`![illust]` 标记行）
- [ ] 标题行位置一致（`#`）
- [ ] `◆◆◆` 分隔行位置一致
- [ ] `![illust](images/…)` 插图标记位置一致
- 工具：`scripts/verify_alignment.py <jp_dir> <cn_dir> [章节名...]`

## 二级：全卷 QA（进入打包前）

- [ ] 禁用表记：错别字/繁体残留（如 志穂→志穗、真島→真岛）、系列禁用译法（如 哥哥大人）
- [ ] 假名残留：正文无日文假名（允许名单：作者/插画师名等，如 平つくね/滝沢慧；奥付等保留日文的文件排除）
- [ ] 术语一致性：核心术语计数合理、禁用变体不出现（如 出租哥哥 vs 租借哥哥）
- [ ] 段落长度比：CN/JP <0.25 或 >3 报警（排查漏译/误删/串行）
- [ ] 连续重复段落（完全相同）检查
- [ ] Markdown 残留（`**`、`##`、`[illust]` 未转换等）
- [ ] 称呼与术语与 glossary/characters 核对（抽查）
- [ ] （无官方中译时）全卷术语/专名清单核对：术语计数 + 每个专名至少抽查 3 处译法一致
- 工具：`scripts/check_kana.py <cn_dir> --exclude colophon` + 项目 QA 脚本（参考实现：`qa_*.py`）

## 三级：打包验证（交付前）

- [ ] 竖排验证（vs 日文原版）：文件清单、仅预期变化、字节一致、结构保留、链接/锚点、无假名
- [ ] 横排验证（vs 竖排备份）：差异白名单、无 vrtl 残留、sep-break 计数、OPF/语言/方向
- [ ] 渲染抽查：横排、2em 缩进、◆◆◆ 位置、标题样式（截图留存，测完关闭进程）
- [ ] 成品内容抽查：随机/重点段落与译稿一致（无回写遗漏）
- [ ] （自建 EPUB，无原版可 diff）结构验证：mimetype/OPF/nav/链接锚点合法；正文与译稿 md 段落映射一致；CSS 生效（渲染）；无假名残留
- [ ] 已知例外逐条记录（如外字图片移除）并说明影响
- 工具：`validate_*.py`（参考实现：竖排/横排各一个）

## 修订回合（收到审核意见后）

- [ ] 逐项回原文核对（确认/驳回都要有依据）
- [ ] 只改必要行；改后重跑一级 + 二级
- [ ] 重新打包 + 与修复前逐文件 diff（仅预期文件变化）
- [ ] 汇报修改前后对照与验证结果
