# 无官方中译时的术语与风格基线

> 适用：只有日文原版（无任何官方/可靠中文对照译本）。核心变化：TM 与术语库不再"对齐得来"，而是**自建**；一致性保障更依赖流程纪律与 QA。

## 1. 术语先行（开译前的准备）

1. **扫描原文**：通读目录 + 每章抽样；用频率统计找出高频专名（人名、地名、组织、招式、道具）与反复出现的术语。
   - 人名可用 ruby/读音资料（EPUB 的 ruby、官方读音页、网络资料）确认读音，再定中文写法。
2. **定译并建库**：
   - `glossary.md`：术语表（日文 / 读音 / 中文 / 备注）；
   - `characters.md`：人物（自称、称呼、语感、称呼总表）；
   - `style-guide.md`：文风与标点基线。
3. **未定项用占位**：翻译中遇到新术语，先标 `TODO` 或统一占位，**定稿前回填**并全卷替换；禁止随手翻（同一词前后不一）。
4. 定译原则：优先中文通行译法；人名保留日式表记的转写惯例（如 佐々木→佐佐木）；谐音/双关尽量保意。

## 2. 自建翻译记忆（TM）

- 把自己**既往已交付的译本**（同系列、同作者、或同一译者的其他作品）按句子切分入库（`jp` / `zh` / `tags`）。
- 新卷翻译时照常"先查 TM"——查的是**自己的风格**（称呼处理、句尾、语气词译法）。
- 每完成一卷，把新译文增量入 TM；跨卷风格越来越稳。
- 若完全没有既往译本：TM 为空属正常，风格锚改由 `style-guide.md` + 对白分桶承担（分桶可随译随建）。

## 3. 风格基线

- 写 `style-guide.md`：叙述文体、对白处理、称呼本地化、标点符号规则、数字/单位处理。
- 可参照同类出版译作（轻小说官方中译）定调，但仅作**风格参考**，不建 TM 条目、不照搬措辞。
- 对白分桶：随翻译进度按角色归集（自己译的句子），供后续章节/卷保持语感。

## 4. 一致性保障（QA 权重调整）

- 术语计数检查权重提高：每个核心术语/专名在 QA 脚本中列入计数名单；禁用变体（错译、异体）列入黑名单。
- 专名抽查：每个专名至少抽查 3 处译法一致（不同章节）。
- 跨卷共用同一套 glossary/characters；新卷只做**增量**，不重建。
- 卷末复核：TODO 占位清零、术语表与正文一致、称呼总表与实际对白一致。

## 5. 后续拿到官方中译时（可选增量）

- 可补做对齐（见 [workflow.md](workflow.md) 第 2 节"有官方中译"），用于：
  - 校准自建术语（官方译法更通行时）；
  - 补充 TM 例句；
  - 发现并修正自己译本中的偏差（以日文原文为准）。
- 已交付的旧卷不必回改，除非用户要求；新卷起采用校准后的术语即可。
