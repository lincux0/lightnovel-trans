# 无官方中译时的术语与风格基线

> 适用：没有可用于本任务的中文对照译本时。术语记录、TM 和对白分桶按作品规模与复用价值选择；本页中的译名仅为说明性示例。

## 1. 术语先行（开译前的准备）

1. **识别关键项**：开译前查看目录和可用原文，找出重要专名、称呼与反复出现的术语；小型单卷可边译边记录，不必先建完整词库。
   - 人名可用 ruby/读音资料（EPUB 的 ruby、官方读音页、网络资料）确认读音，再定中文写法。
2. **按需记录**：
   - `glossary.md`：术语表（日文 / 读音 / 中文 / 备注）；
   - `characters.md`：人物（自称、称呼、语感、称呼总表）；
   - `style-guide.md`：文风与标点基线。
3. **未定项留痕**：遇到关键未定术语，可用 `TODO` 或统一占位并在定稿前回查；不确定项不要伪装成已确认译名。
4. 定译时考虑中文习惯、原文读音与语义、作品内线索和用户要求；例如「佐々木→佐佐木」只是日文人名转写示例，不是所有姓名的固定规则。谐音/双关按语境权衡保意与可读性。

## 2. 自建翻译记忆（TM）

- TM 是可选项；只有存在重复使用价值且项目允许保存时再维护，不要求单卷翻译先建空库。
- 自译句只有在回看日文、确认语义与语境后才能作为候选条目；记录 `jp` / `zh` / `tags` 和适用语境。优先使用项目已有译例，跨作品参考不覆盖当前作品约定，不自动上传或在任务范围外复制语料。
- 查询 TM 是参考，不是复制命令；先确认当前语境适用再采用。角色关系或时间变化可能使同一词有不同译法，记录各自条件，不强求全卷同译。
- 没有合适 TM 时留空即可；可用简短风格说明和人工核对，不必创建对白分桶。

## 3. 风格基线

- 按需记录叙述文体、对白、称呼、标点与数字处理；简短单卷可直接使用用户给出的要求。
- 用户提供或项目已有的参考译作可作风格参考，不将其措辞直接搬入译文或 TM。
- 对白分桶只在角色声线、篇幅或后续复用值得维护时建立；归属不确定的例句标为未知。

## 4. 一致性保障（QA 权重调整）

- 对有词库的项目，可检查已确认的专名和禁用表记；计数结果只提示候选，不自动判错。
- 按词项的出现频率和风险抽查；样本少或只出现一次时明确记录，不能要求每个词都抽查固定次数。
- 系列可沿用经过核实的术语信息；先检查新语境。词形相同但人物关系、时间或语义不同，可以合法采用不同译法。
- 定稿前处理未决占位并核对高风险术语；数量和一致性统计不是语义正确的证明。

## 5. 后续拿到官方中译时（可选增量）

- 拿到可用于本项目的官方译文时，可按需补做对齐（见 [workflow.md](workflow.md) 第 2 节），用于：
  - 校准自建术语（官方译法更通行时）；
  - 补充 TM 例句；
  - 发现并修正自己译本中的偏差（以日文原文为准）。
- 对齐结果必须人工回到日文核实后再采用；不得因官方译法不同就自动改写已有译文。旧卷是否修订按用户指示处理。
