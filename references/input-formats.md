# 输入形态适配：EPUB / TXT / Word / 其他

> 目标：先得到可翻译、可回查的文本；不要求不同来源都变成同一套完整结构。只有用户要求打包时，才补充该格式所需的元数据与资源。

## 工作文本约定（按需采用）

- 可将章节整理为 `chapters/*.md`，以 `# 标题` 标明章节、按源段分段；保留有意义的首行缩进与独立分隔符。输入的软换行先结合原版面判断并重建段落。
- 随附 `txt_to_md.py` 仅生成 `chapters/` 与 `toc.md`。`chapters.json`、`full.md`、`images/` 按目标项目工具和实际交付需要再建，不宣称所有格式适配都产出同构目录。
- 保留来源文件及可回查的章节/段落位置。章节数、字符数、段落数和图片数只能提示结构差异，不能证明内容完整或语义正确。

## 1. EPUB（需目标项目适配工具）

- 按 spine 与目录整理章节时，保留 ruby/tcy 底字及读音等翻译辅助信息；外字图片可能包含正文字符，应保留引用或确认字符后再处理。检查脚注、链接和行内内容是否遗漏。
- EPUB 提取和回写工具不随本 skill 提供。回写前确认工具保留结构、读音与外字语义；只有用户要求 EPUB 时才执行 [epub-packaging.md](epub-packaging.md) 中适用的流程。

## 2. TXT

- **编码**：优先来源声明或用户指定。脚本 `auto` 按 UTF-8 → CP932 → EUC-JP 回退尝试，成功解码不代表正确识别；抽样核对文本，歧义时用 `--encoding` 指定。
- **章节切分**：正则匹配章节行，例如：
  - `^\s*(第[0-9一二三四五六七八九十百]+[章話回]|プロローグ|エピローグ|序章|終章|幕間|あとがき|特別短編).*$`
  - 上述模式只是示例。作品格式不同，先查看章节标题与相邻正文，确认切分结果再处理。
- **段落**：
  - 常见：一行一段（日文小说 TXT 多为此）。
  - 硬换行版：可用空行分段（`--paragraph-mode blank`）；该模式保留段首缩进及独立分隔符。可重复传入 `--separator` 指定额外独立分隔行。
- **插图**：TXT 无图。若附带图片目录：按文件名（001.jpg…）顺序在对应章节/位置插入 `![illust](images/xxx)`，位置需对照原书/网络版人工确认。
- **ruby 读音**：TXT 通常丢失。专名读音以官方资料/词典核对，记入 glossary（用于后续卷一致性）。
- 随附 `scripts/txt_to_md.py` 只生成 `chapters/` 与 `toc.md`；输出目录非空时拒绝运行，`--min-chapter-lines` 只警告、不删除章节。运行前抽样确认切分与段落模式。

## 3. Word / docx

- **段落与标题**：可读取 `word/document.xml` 中的 `w:p`；标题样式可作章节切分依据，无样式时结合章节文字判断。
- **图片**：docx 本质是 zip：
  - 图片在 `word/media/`；
  - `word/_rels/document.xml.rels` 给出 r:embed → 文件映射；
  - `w:drawing`/`w:pict` 出现的位置即插图位置（插画页可近似处理）。
- **注音（ruby）**：DOCX 中可能真实存在 ruby XML。工具可读取时保留底字与读音辅助信息；确已丢失时不要猜测恢复。
- **工具**：
  - `python-docx`（最省事）：`Document(path).paragraphs`，按 `paragraph.style.name` 判标题；
  - 无第三方依赖：标准库 `zipfile` + `xml.etree.ElementTree`；`lxml` 是第三方库，仅在项目已有时使用。
- **遗漏风险**：表格、文本框、脚注/尾注、图片及关系可能遗漏或乱序，需逐项抽查。不要尝试解除受限内容的保护。

## 4. 其他来源

| 来源 | 做法 |
|---|---|
| HTML / 网页 | 使用目标项目可用工具保留标题与段落；确认图片、分页和脚注遗漏风险 |
| azw3 / mobi | 若目标环境有可用转换工具，可转成便于处理的格式；抽查转换结果 |
| PDF | 使用目标环境已有文本提取或 OCR 工具；扫描识别和段落重建需人工校对，记录不确定处 |

## 5. 可选交付格式

按用户目标交付译稿、审核报告、修订后的源格式或其他指定格式。用户明确要求 EPUB 且没有原版可回写时，才按 [epub-packaging.md](epub-packaging.md) 自建；无 EPUB 需求则跳过打包。
